    Tentang LensLingo

    LensLingo adalah aplikasi pembelajaran bahasa Inggris berbasis visual (Project Based Learning) yang mengidentifikasi benda di sekitar Anda menggunakan kecerdasan buatan Google Gemini.

    Privasi & Keamanan

    Foto yang diambil dianalisis secara sementara menggunakan Gemini API Free Tier. Server LensLingo tidak menyimpan foto dan tidak mencatat data foto ke log.

    Desain & Teknologi

    Dibuat menggunakan HTML5, CSS3 murni (Palet Sage), dan JavaScript modern tanpa framework.
